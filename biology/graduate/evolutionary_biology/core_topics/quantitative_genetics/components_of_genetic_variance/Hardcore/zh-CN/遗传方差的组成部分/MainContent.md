## 引言
对于那些由众多基因和环境因素共同决定的复杂性状，如作物的产量、动物的体型或人类对疾病的易感性，我们如何理解其遗传规律并预测其进化趋势？数量遗传学为回答这一核心问题提供了强大的理论框架。它通过分析群体中的表型变异，将观察到的差异分解为遗传和环境的贡献。然而，简单地将表型归因于“遗传”是远远不够的。为了准确预测性状如何响应自然或人工选择，以及亲代性状如何传递给后代，我们必须深入剖析遗传变异本身的内在结构。

本文旨在系统性地揭示构成总遗传方差的各个组分。我们将超越基础的“表型 = 基因型 + 环境”模型，探讨遗传效应如何被统计地分解为可预测的加性部分和更复杂的非加性部分（显性与上位性）。通过学习本文，你将掌握区分这些遗传方差组分背后的原理，理解为何只有加性遗传方差直接决定了性状的进化潜力，并了解这些看似抽象的概念如何在现实世界中得到估算和应用。

接下来的内容将分为三个核心章节。在“**原理与机制**”中，我们将从第一性原理出发，推导加性、显性及上位性方差的定义，并阐明它们为何是群体的属性而非基因的内在属性。在“**应用与跨学科联系**”中，我们将探讨如何通过实验设计和统计模型（如动物模型）来估算这些方差组分，并展示它们在预测进化响应、理解局域适应（$Q_{ST}$ vs $F_{ST}$）以及连接生态学与发育生物学中的关键作用。最后，“**动手实践**”部分将通过具体的计算练习，帮助你巩固对这些核心概念的理解。

## 原理与机制

继前一章介绍数量遗传学的基本框架之后，本章将深入探讨构成表型变异的核心组成部分——遗传方差和环境方差的原理与机制。我们将系统性地剖析这些组分，并阐明它们在预测进化响应和理解复杂性状遗传结构中的关键作用。

### 表型方差：基本划分

一个生物体表现出的可测量性状（即**表型**，**phenotype**）是其遗传构成（**基因型**，**genotype**）与所处环境（**environment**）共同作用的结果。在数量遗传学中，我们通常从一个最基本的线性模型开始，将个体的表型值 ($P$) 分解为基因型效应 ($G$) 和环境离差 ($E$) 的和：

$P = G + E$

在这个模型中，$G$ 代表了由个体遗传物质决定的表型期望值，而 $E$ 则代表了所有非遗传因素导致的与该期望值的偏离。按照惯例，我们将这些效应中心化，使得在整个群体中，基因型效应和环境离差的平均值均为零，即 $\mathbb{E}[G] = 0$ 和 $\mathbb{E}[E] = 0$。

我们更关心的是群体中性状的变异，而非单个个体的表型值。群体的总表型方差 ($V_P$) 可以通过对其组分求方差来得到。根据方差的基本性质，两个随机变量之和的方差等于它们各自方差之和，再加上它们协方差的两倍。因此，表型方差的完整分解为 [@problem_id:2697779]：

$V_P = \mathrm{Var}(G+E) = \mathrm{Var}(G) + \mathrm{Var}(E) + 2\mathrm{Cov}(G,E)$

这里，$V_G$ 是**遗传方差**（**genetic variance**），$V_E$ 是**环境方差**（**environmental variance**），而 $\mathrm{Cov}(G,E)$ 是**基因型-环境协方差**（**genotype-environment covariance**）。

#### 基因型-环境协方差与互作

在方差分解公式中，协方差项 $\mathrm{Cov}(G,E)$ 具有重要的生物学意义。它衡量的是特定基因型与特定环境相关联的趋势。当 $\mathrm{Cov}(G,E) \neq 0$ 时，我们称之为存在**基因型-环境相关**（**genotype-environment correlation**）。例如，在自然种群中，具有更强抗旱能力的植物基因型可能更常出现在干旱的生境中；在农业实践中，产量最高的作物品种（优良基因型）往往被种植在最肥沃的土壤中（优良环境）。这些都是正向基因型-环境相关的例子 [@problem_id:2697779]。

在许多情况下，为了简化分析和估计遗传参数，研究者需要确保 $\mathrm{Cov}(G,E) = 0$。这可以通过实验设计来实现，例如在**共同花园实验**（**common garden experiment**）中，将不同基因型的个体随机分配到各种环境中，从而人为地打破基因型与环境之间的任何非随机关联。在自然条件下，只有当个体的栖息地选择、亲代效应或其他行为不存在将特定基因型与特定环境联系起来的系统性模式时，该协方差项才会趋近于零。

必须严格区分基因型-环境相关（$\mathrm{Cov}(G,E)$）和另一个重要概念——**基因型-环境互作**（**genotype-environment interaction**，$G \times E$）。基因型-环境相关描述的是基因型和环境这两种**原因**之间的统计关联，而基因型-环境互作则描述的是这两种原因对表型这一**结果**的非加性效应。当存在 $G \times E$ 互作时，不同基因型在不同环境下的表现相对优劣会发生变化。在图形上，这表现为不同基因型的**反应范式**（**reaction norms**）不相互平行。

考虑到 $G \times E$ 互作，一个更完整的表型模型可以写为：

$P = G + E + G \times E + R$

其中 $G \times E$ 项代表互作效应，而 $R$ 代表不可控的、随机的微环境残差。此时，总表型方差的分解也变得更为复杂 [@problem_id:2697722]：

$V_P = V_G + V_E + V_{G \times E} + V_R + 2\mathrm{Cov}(G,E) + \dots$

其中 $V_{G \times E}$ 是由基因型-环境互作产生的方差。只有在满足特定统计条件（如通过平衡的实验设计和随机化，确保所有主效应和互作效应项相互**正交**，即不相关）时，所有的协方差项才为零，方差分解才能简化为各项方差的直接加和：

$V_P = V_G + V_E + V_{G \times E} + V_R$

### 遗传方差的分解：加性与非加性组分

遗传方差 $V_G$ 本身是理解性状遗传力的关键，但它并非一个整体。根据其对后代遗传的贡献方式，我们可以将其进一步分解为几个关键组分。这种分解是数量遗传学的核心，因为它揭示了为什么亲子之间会相似，以及为什么选择能够导致进化。总遗传方差 $V_G$ 可以分解为**加性遗传方差**（**additive genetic variance**，$V_A$）、**显性方差**（**dominance variance**，$V_D$）和**上位性方差**（**epistatic variance**，$V_I$）：

$V_G = V_A + V_D + V_I$

这个分解的精髓在于，它是一种基于群体等位基因频率和效应的**统计抽象**，而非直接对应于等位基因在分子水平上的生化作用。下面我们将逐一剖析这些组分。

#### 加性遗传方差（$V_A$）与育种值

在所有遗传方差组分中，加性遗传方差 $V_A$ 最为重要，因为它是决定亲代性状向子代传递程度以及性状对选择响应能力的主要因素。

要理解 $V_A$，我们必须首先引入**育种值**（**breeding value**）的概念。一个个体的育种值 ($A$) 是其作为亲本时，能够传递给后代的遗传价值的期望。从统计学上讲，育种值被定义为基因型值 ($G$) 对该个体所携带的特定等位基因数量的最佳线性预测。换句话说，它是通过线性回归模型从等位基因构成来预测基因型值的结果 [@problem_id:2697755]。

这个回归模型的斜率，被称为**等位基因的平均替换效应**（**average effect of allele substitution**），用 $\alpha$ 表示。考虑一个双等位基因座（等位基因为 $A$ 和 $a$），$\alpha$ 衡量的是在群体中，用一个 $A$ 等位基因随机替换一个 $a$ 等位基因时，对表型产生的平均效应。这个“平均”至关重要，因为它是在群体所有可能的遗传背景下取平均得到的。一个重要的推论是，$\alpha$ 的值不仅取决于等位基因的内在效应，还取决于群体中的等位基因频率。

对于一个双等位基因座，其基因型值分别为 $G_{AA}$、$G_{Aa}$ 和 $G_{aa}$，我们可以定义纯合子效应差的一半为 $a = (G_{AA} - G_{aa})/2$，杂合子偏离纯合子中点的程度为 $d = G_{Aa} - (G_{AA} + G_{aa})/2$。通过推导可以证明，平均替换效应 $\alpha$ 的表达式为 [@problem_id:2697775]：

$\alpha = a + d(q - p)$

其中 $p$ 和 $q$ 分别是等位基因 $A$ 和 $a$ 的频率。这个公式清晰地表明，只要存在显性效应（即 $d \neq 0$），$\alpha$ 的值就会随着等位基因频率 $p$ 的变化而改变。只有在纯加性效应（$d=0$）的情况下，$\alpha$ 才是一个不依赖于群体频率的常数 ($a$)。

个体的育种值 $A$ 便是基于 $\alpha$ 和该个体的等位基因数目计算得出的。例如，对于基因型 $AA$、$Aa$ 和 $aa$（$A$ 等位基因数目分别为2, 1, 0），其育种值（相对于群体均值）分别为 $2\alpha q$, $\alpha(q-p)$ 和 $-2\alpha p$。

最后，**加性遗传方差 ($V_A$)** 被定义为群体中所有个体**育种值的方差**。对于单个基因座，在Hardy-Weinberg平衡下，其表达式为：

$V_A = 2pq\alpha^2 = 2pq[a + d(q-p)]^2$

这个公式揭示了 $V_A$ 的核心特性：它依赖于群体的多态性（由 $2pq$ 体现）和等位基因的平均替换效应 $\alpha$。

例如，考虑一个基因座，其基因型值为 $G_{AA} = 12$, $G_{Aa} = 7$, $G_{aa} = 5$。在一个 $p = f(A) = 0.25$ 的群体中，我们可以计算出 $\alpha = 2.75$。因此，基因型 $AA$, $Aa$, $aa$ 的育种值分别为 $4.125$, $1.375$, 和 $-1.375$。该群体中的加性遗传方差为 $V_A = 2(0.25)(0.75)(2.75)^2 \approx 2.836$ [@problem_id:2697755]。

#### 显性方差（$V_D$）

基因型值中不能被加性模型（即育种值）所解释的部分，被称为**显性离差**（**dominance deviation**，$\delta$）。它是基因型值 $G$ 与其育种值 $A$ 之间的差值：$\delta = G - A$（在中心化后）。显性离差源于在同一基因座上两个等位基因之间的相互作用（即显性效应）。它是线性回归模型中的残差。

根据最小二乘法回归的性质，群体中显性离差的加权平均值必然为零 [@problem_id:2697734] [@problem_id:2697766]。而**显性方差 ($V_D$)** 被定义为这些显性离差在群体中的方差。

$V_D = \mathrm{Var}(\delta) = \mathbb{E}[\delta^2] - (\mathbb{E}[\delta])^2 = \mathbb{E}[\delta^2]$

对于单个基因座，在Hardy-Weinberg平衡下，其表达式为：

$V_D = (2pqd)^2$

与 $V_A$ 一样，$V_D$ 也依赖于等位基因频率和显性效应的大小。

#### 方差组分的群体依赖性

至此，一个核心概念已然浮现：**遗传方差的组分是群体的统计属性，而非基因或个体的内在属性**。即使一个基因的分子生物学功能（即从基因型到表型值的映射）保持不变，其在不同群体中所产生的加性方差和显性方差也可能截然不同。

一个极具启发性的例子可以阐明这一点 [@problem_id:2697705]。考虑一个单基因座性状，基因型值分别为 $G_{AA}=0$, $G_{Aa}=1$, $G_{aa}=0$。这是一个完全显性的情况，杂合子的表型值最高。
- 在一个等位基因频率为 $p=0.5$ 的群体中，我们计算可得 $\alpha = q-p = 0.5-0.5 = 0$。因此，加性遗传方差 $V_A = 2pq\alpha^2 = 0$。此时，全部的遗传方差都是显性方差，$V_G = V_D = 0.25$。直观地理解，当 $p=0.5$ 时，携带一个 $A$ 等位基因的个体（$AA$ 或 $Aa$）与不携带 $A$ 的个体（$aa$）相比，其表型没有系统性的增加或减少，线性回归无法捕捉到任何加性效应。
- 现在，考虑另一个群体，其等位基因频率为 $p=0.9$。此时，$\alpha = 0.1-0.9 = -0.8$。$V_A$ 显著大于零（$V_A \approx 0.1152$），而 $V_D$ 则减小（$V_D \approx 0.0324$）。

这个例子雄辩地证明，即使底层的基因型-表型映射完全相同，仅因群体等位基因频率的差异，遗传方差的构成（$V_A$ 与 $V_D$ 的相对比例）就可以发生剧烈变化。因此，当我们讨论一个性状的遗传结构时，必须始终将其置于特定的群体背景之中。这一原则也同样适用于受近交等因素影响的群体结构，因为近交会改变基因型频率，从而改变方差组分计算的统计基础 [@problem_id:2697766]。

#### 上位性方差（$V_I$）

当一个性状受多个基因座影响时，不同基因座的等位基因之间可能存在相互作用，这种现象被称为**上位性**（**epistasis**）。在统计遗传学中，**上位性方差 ($V_I$)** 指的是基因型值中不能被所有单个基因座的加性效应和显性效应之和所解释的方差部分。它是对单基因座模型进行扩展后的残差方差 [@problem_id:2697710]。

类似于将 $G$ 分解为 $A$ 和 $D$，上位性互作本身也可以被进一步分解为不同类型的互作方差，例如：
- **加性-加性互作方差 ($V_{AA}$)**：由两个不同基因座的加性效应之间的互作产生。
- **加性-显性互作方差 ($V_{AD}$)**：由一个基因座的加性效应与另一个基因座的显性效应之间的互作产生。
- **显性-显性互作方差 ($V_{DD}$)**：由两个不同基因座的显性效应之间的互作产生。

以及更高阶的互作。这个分解可以通过使用一套正交的统计编码来实现，它确保了在连锁平衡的群体中，所有方差组分（$V_A, V_D, V_{AA}, V_{AD}, \dots$）都是相互独立的 [@problem_id:2697710]。

例如，一个精心设计的双基因座模型可以清晰地展示 $V_{AA}$ 的来源 [@problem_id:2697782]。假设一个性状的基因型值如下：$G_{AABB}=+2, G_{AAbb}=-2, G_{aaBB}=-2, G_{aabb}=+2$，所有其他基因型（包含任何一个杂合位点）的值均为0。在这个模型中，任何单个基因座的效应都被平均掉了（例如，在 $B/b$ 基因座的随机背景下，$AA$ 基因型的平均值为0），因此不存在单基因座的显性效应（$V_D=0$）。然而，两个基因座的组合效应却很显著。这种互作效应贡献了加性-加性上位性方差 $V_{AA}$。与所有其他方差组分一样，$V_{AA}$ 的大小也依赖于两个基因座的等位基因频率。只有当两个基因座都存在多态性时，$V_{AA}$ 才可能大于零；任何一个基因座被固定，互作方差都将消失。

### 方差划分的意义：预测亲缘个体间的相似性

我们之所以不遗余力地将遗传方差分解为如此精细的组分，其根本原因在于：**不同的遗传方差组分以不同的方式遗传给后代**。理解这一点是预测亲缘个体间表型相似性（如亲子、兄弟姐妹）以及预测群体对选择响应的基础。

我们以**亲子（parent-offspring）**关系为例进行分析 [@problem_id:2697753]。在随机交配的群体中，子代从亲代那里继承了一半的等位基因，而另一半则来自随机选择的另一个亲本。这种遗传机制决定了不同方差组分的贡献。

- **加性遗传方差 ($V_A$) 的贡献**：育种值 ($A$) 的定义本身就反映了其可加和的、可传递的特性。子代的期望育种值是其双亲育种值的平均值。因此，亲代和子代育种值之间的协方差为 $\mathrm{Cov}(A_P, A_O) = \frac{1}{2}V_A$。这意味着，平均而言，一半的加性遗传方差贡献给了亲子间的相似性。

- **显性方差 ($V_D$) 的贡献**：显性离差是特定基因座上两个等位基因互作的结果。子代只从一个亲本那里获得该基因座上的一个等位基因，另一个等位基因来自配偶。因此，亲代的显性互作组合在传代过程中被打破并重新组合。结果是，亲代与子代之间的显性离差不存在协方差，即 $\mathrm{Cov}(D_P, D_O) = 0$。因此，**显性方差不贡献于亲子间的表型相似性**。

- **上位性方差 ($V_I$) 的贡献**：上位性方差的贡献更为复杂。由于减数分裂中的重组，亲代中相互作用的等位基因组合会被打散。加性-加性互作方差 ($V_{AA}$) 会以 $\frac{1}{4}V_{AA}$ 的比例贡献于亲子协方差，但所有涉及显性效应的互作方差（如 $V_{AD}, V_{DD}$）均不贡献于亲子协方差。

综上所述，亲代与子代基因型值之间的协方差为：

$\mathrm{Cov}(G_P, G_O) = \frac{1}{2}V_A + \frac{1}{4}V_{AA} + \text{更高阶加性互作项...}$

这个公式是数量遗传学的基石之一。它明确指出，**加性遗传方差 $V_A$ 是决定亲子相似性的主要遗传因素**。正是因为这个原因，$V_A$ 通常被称为“可遗传的方差”，它直接决定了性状响应选择的潜力。狭义遗传力 ($h^2 = V_A/V_P$) 之所以如此重要，也正是因为它量化了这种可遗传变异在总表型变异中所占的比例。
