## 引言
在电解质溶液的导电过程中，电流由正负离子的定向迁移共同构成。然而，不同离子对总电流的贡献并非均等，理解并量化每种离子的贡献是电化学研究与应用的核心。离子迁移数（或输运数）正是为解决这一问题而引入的关键物理量，它直接关联着微观的离子运动与宏观的电化学现象。缺乏对迁移数的深入理解，我们将难以解释液接电势等测量误差的来源，也无法高效地设计电池电解液或开发离子选择性分离技术。本文旨在系统性地填补这一知识空白，为读者提供一个关于迁移数的完整视图。在接下来的内容中，我们首先将在“原则与机理”一章中奠定理论基础，详细定义迁移数，并探讨其与离子淌度、电导率的关系及背后的微观机理。随后，我们将在“应用与交叉学科联系”一章中，展示迁移数如何在电化学分析、能源材料和生命科学等前沿领域发挥关键作用。最后，通过“动手实践”部分，您将有机会运用所学知识解决实际问题。让我们从探究迁移数的基本原理开始。

## 原则与机理

在电解质溶液中，施加电场时，正负离子分别向相反方向迁移，共同构成了电流。然而，不同种类的离子对总电流的贡献通常是不同的。为了量化特定离子种类对电荷输运的贡献，我们引入了**迁移数**（transport number），有时也称为**传递数**（transference number）这一关键概念。本章将深入探讨迁移数的定义、其与宏观电导性质的联系、实验测量方法，并剖析影响离子迁移能力的微观机理。

### 迁移数的定义与计算

离子的**迁移数**，用 $t_i$ 表示，定义为在电解过程中由该离子（$i$）所携带的电流 $I_i$ 占总电流 $I$ 的分数：

$t_i = \frac{I_i}{I}$

由于总电流是所有离子携带的电流之和，即 $I = \sum_j I_j$，因此所有离子的迁移数之和恒等于1：

$\sum_j t_j = 1$

离子在溶液中携带的电流取决于其电荷、浓度和在外电场中的迁移速率。在电场强度为 $E$ 的作用下，离子 $i$ 的平均迁移速率 $v_i$ 与电场强度成正比，比例常数被称为**离子淌度**（ionic mobility），用 $u_i$ 表示：

$v_i = u_i E$

离子淌度 $u_i$ 是一个表征离子在单位电场下迁移快慢的物理量。因此，由离子 $i$ 产生的电流密度 $j_i$ 可以表示为：

$j_i = |z_i| F c_i v_i = |z_i| F c_i u_i E$

其中，$z_i$ 是离子的电荷数，$F$ 是法拉第常数，$c_i$ 是离子的摩尔浓度。总电流密度 $J$ 是所有离子电流密度的总和。因此，离子 $i$ 的迁移数可以表示为：

$t_i = \frac{|z_i| c_i u_i}{\sum_j |z_j| c_j u_j}$

对于一个简单的 $1:1$ 型电解质（如 NaCl 或问题 [@problem_id:1599667] 中提到的XY盐），溶液中 $c_+ = c_- = c$ 且 $|z_+| = |z_-| = 1$。此时，阳离子和阴离子的迁移数可以简化为只与淌度相关的形式：

$t_+ = \frac{u_+}{u_+ + u_-}$  和  $t_- = \frac{u_-}{u_+ + u_-}$

### 迁移数与摩尔电导率的关系

在实际应用中，我们更常使用**摩尔电导率**（molar conductivity）来描述电解质的导电能力。离子的**摩尔离子电导率** $\lambda_i$ 与其淌度 $u_i$ 之间存在直接关系：

$\lambda_i = |z_i| F u_i$

将此关系代入迁移数的表达式，我们得到一个更实用的计算公式，它将迁移数与可直接测量的电导率联系起来：

$t_i = \frac{c_i \lambda_i}{\sum_j c_j \lambda_j}$

根据**科尔劳施离子独立运动定律**（Kohlrausch's law of independent ionic migration），在无限稀释条件下，电解质的极限摩尔电导率 $\Lambda_m^\circ$ 等于其组分离子的极限摩尔离子电导率 $\lambda_i^\circ$ 的总和，并乘以化学计量系数 $\nu_i$：

$\Lambda_m^\circ = \sum_i \nu_i \lambda_i^\circ$

因此，在无限稀释时，离子 $i$ 的迁移数 $t_i^\circ$ 为：

$t_i^\circ = \frac{\nu_i \lambda_i^\circ}{\Lambda_m^\circ} = \frac{\nu_i \lambda_i^\circ}{\sum_j \nu_j \lambda_j^\circ}$

这个关系式为我们通过电导率数据计算迁移数提供了理论基础。例如，考虑一个 1:1 型电解质 XY 的稀溶液，其阳离子迁移数为 $t_+^\circ$，总极限摩尔电导率为 $\Lambda_m^\circ$。我们可以方便地计算出阴离子的极限摩尔离子电导率 $\lambda_-^\circ$。因为 $t_+^\circ = \lambda_+^\circ / \Lambda_m^\circ$ 且 $\Lambda_m^\circ = \lambda_+^\circ + \lambda_-^\circ$，可以推导出：[@problem_id:1599667]

$\lambda_-^\circ = \Lambda_m^\circ - \lambda_+^\circ = \Lambda_m^\circ - t_+^\circ \Lambda_m^\circ = \Lambda_m^\circ (1 - t_+^\circ)$

对于更复杂的电解质，如 $\text{MgCl}_2$，解离为 $\text{Mg}^{2+}$ 和 $2\text{Cl}^-$，计算时必须考虑化学计量系数。其极限摩尔电导率为 $\Lambda_m^\circ(\text{MgCl}_2) = \lambda^\circ(\text{Mg}^{2+}) + 2\lambda^\circ(\text{Cl}^-)$。氯离子的迁移数则应表示为它对总电导率的贡献分数：[@problem_id:1599679]

$t_{\text{Cl}^-}^\circ = \frac{2 \lambda^\circ(\text{Cl}^-)}{\lambda^\circ(\text{Mg}^{2+}) + 2 \lambda^\circ(\text{Cl}^-)} = \frac{2 \lambda^\circ(\text{Cl}^-)}{\Lambda_m^\circ(\text{MgCl}_2)}$

通过这些公式，只要已知总摩尔电导率和其中一种离子的摩尔离子电导率，就可以计算出另一种离子的摩尔离子电导率以及两种离子的迁移数。

### 迁移数的实验测量

迁移数是可以通过实验直接测定的物理量。两种经典的测量方法是希托夫法（Hittorf's method）和界面移动法（moving boundary method）。

**界面移动法**是一种直观且精确的测量方法。在一个均匀的通道中，将待测电解质（称为“前导电解质”，leading electrolyte）与另一种具有一个相同离子且密度较大的“指示电解质”（indicator electrolyte）小心地分层，形成一个清晰的界面。施加电流后，离子开始迁移，界面也随之移动。[@problem_id:1599669]

以测量 HCl 溶液中 $\text{H}^+$ 迁移数为例，可将 HCl 作为前导电解质，$\text{CdCl}_2$ 作为指示电解质。当阴极置于 HCl 区域，阳极置于 $\text{CdCl}_2$ 区域时，$\text{H}^+$ 和 $\text{Cd}^{2+}$ 离子都向阴极移动。在时间 $t$ 内，通过恒定电流 $I$ 导致界面移动了体积 $V$。这意味着体积 $V$ 内的所有阳离子（这里是 $\text{H}^+$）都已完全迁移通过了初始界面所在的位置。这些阳离子携带的电荷量为 $Q_+ = z_+ F n_+ = z_+ F c_+ V$。这部分电荷占总通过电荷 $Q_{total} = I t$ 的分数就是阳离子的迁移数：

$t_+ = \frac{Q_+}{Q_{total}} = \frac{z_+ F c_+ V}{I t}$

通过精确测量 $I, t, c_+, V$，就可以计算出阳离子的迁移数。

该实验成功的关键在于维持一个稳定、清晰的界面。这要求指示电解质中的阳离子（如 $\text{Cd}^{2+}$）的迁移速率必须慢于前导电解质中的阳离子（如 $\text{H}^+$）。如果指示离子移动得更快，它将超越前导离子，导致界面模糊和混合。因此，选择指示电解质的原则是：其阳离子的淌度必须小于前导阳离子的淌度，即 $u_{indicator}  u_{leading}$。[@problem_id:1599677] 例如，在测量 NaCl 溶液中 $\text{Na}^+$ 的迁移数时，由于 $\text{Li}^+$ 和四甲基铵离子 $(\text{CH}_3)_4\text{N}^+$ 的淌度都小于 $\text{Na}^+$，因此 LiCl 和 $(\text{CH}_3)_4\text{NCl}$ 都是合适的指示电解质。而淌度大于 $\text{Na}^+$ 的 $\text{K}^+$ 则不适用。

### 微观起源与影响因素

离子的迁移数最终由其在溶液中的微观行为决定。以下几个因素至关重要：

#### 离子尺寸、电荷与溶剂化

一个普遍的误解是认为离子半径越小，其迁移速率就越快。实际上，离子在溶液中并非“裸露”地移动，而是被一层溶剂分子包围，形成一个**溶剂化离子**。离子运动时所受到的阻力主要来自这个溶剂化整体与周围溶剂的摩擦，其有效尺寸被称为**水合半径**（hydrodynamic radius），$r_h$。根据斯托克斯-爱因斯坦关系，淌度 $u_i$ 近似与水合半径成反比 ($u_i \propto 1/r_h$)。

离子的电荷密度（电荷与裸离子半径之比）越高，与极性溶剂分子的相互作用越强，其水合层就越牢固、越庞大，导致水合半径 $r_h$ 增大，淌度反而减小。这就是为什么小半径的 $\text{Li}^+$ 离子的淌度实际上小于大半径的 $\text{K}^+$ 和 $\text{Cs}^+$ 离子的原因。

我们可以通过一个简化模型来理解电荷和水合半径对迁移数的综合影响。假设离子淌度与电荷数 $|z_i|$ 成正比，与水合半径 $r_{h,i}$ 成反比，即 $u_i \propto |z_i|/r_{h,i}$。那么，离子 $i$ 携带的电流密度将正比于 $c_i |z_i|^2 / r_{h,i}$。基于此模型，我们可以比较不同电解质体系中阳离子的迁移数。例如，通过比较 NaCl 和 CaCl$_2$ 溶液，可以发现阳离子的迁移数不仅取决于水合半径，还受到离子电荷平方 $|z_i|^2$ 和溶液化学计量（决定了阴阳离子浓度比）的显著影响。[@problem_id:1599680]

#### Grotthuss机理：H⁺和OH⁻的特殊迁移方式

在水溶液中，氢离子 ($\text{H}^+$) 和氢氧根离子 ($\text{OH}^-$) 的淌度和迁移数异常之高。例如，$\text{H}^+$ 的极限摩尔离子电导率大约是 $\text{K}^+$ 的5倍。这无法用简单的水合模型来解释。[@problem_id:1599707]

这种异常现象源于一种独特的“结构式扩散”机制，称为**Grotthuss机理**。在水中，一个多余的质子 ($\text{H}^+$) 并非作为一个固定的水合氢离子 ($\text{H}_3\text{O}^+$) 整体在溶液中长距离穿行。相反，它通过水分子之间形成的氢键网络进行快速“跳跃”。一个 $\text{H}_3\text{O}^+$ 上的质子可以转移到相邻的水分子上，形成一个新的 $\text{H}_3\text{O}^+$，而原来的分子变回 $\text{H}_2\text{O}$。这个过程就像一个接力赛，电荷在氢键网络中快速传递，其有效迁移速率远高于任何离子的物理移动速率。$\text{OH}^-$ 离子也通过类似的机理（质子从水分子向 $\text{OH}^-$ 跳跃）进行快速迁移。

#### 溶剂效应

离子的迁移数并非其固有属性，而是严重依赖于溶剂的性质。这是因为溶剂不仅提供了离子运动的介质，还通过溶剂化作用直接改变了离子的有效尺寸。[@problem_id:1599689]

以 LiCl 在水（极性质子性溶剂）和乙腈（$\text{CH}_3\text{CN}$，极性非质子性溶剂）中的行为为例。$\text{Li}^+$ 作为小阳离子，在两种溶剂中都会被强烈溶剂化。然而，对于阴离子 $\text{Cl}^-$，情况则大不相同。水分子可以通过氢键有效地溶剂化 $\text{Cl}^-$。而乙腈分子无法提供氢键，对 $\text{Cl}^-$ 的溶剂化作用非常弱。结果是，$\text{Cl}^-$ 在乙腈中的有效半径远小于在水中的有效半径，导致其在乙腈中的淌度大大增加。根据迁移数公式 $t_{\text{Li}^+} = u_{\text{Li}^+} / (u_{\text{Li}^+} + u_{\text{Cl}^-})$，当 $u_{\text{Cl}^-}$ 相对 $u_{\text{Li}^+}$ 急剧增大时，$t_{\text{Li}^+}$ 会显著减小。因此，我们预期 $t_{\text{Li}^+, \text{ACN}}  t_{\text{Li}^+, \text{H}_2\text{O}}$。

#### 温度效应

温度的改变会通过两种主要方式影响离子淌度，从而改变迁移数。首先，升高温度会使溶剂的粘度 $\eta$ 显著下降，这会增大所有离子的淌度 ($u_i \propto 1/\eta$)。其次，温度会影响溶剂化层的结构。[@problem_id:1599684]

对于像 $\text{Li}^+$ 这样具有高电荷密度、在低温下形成牢固有序水合层的离子，升高温度会加剧热运动，有效地“瓦解”这个有序结构，从而显著减小其有效水合半径 $r_{h, \text{Li}^+}$。对于水合层本就不那么有序的离子（如 $\text{Cl}^-$），这种效应则不那么明显。因此，随着温度升高，$\text{Li}^+$ 的淌度增长幅度会不成比例地大于 $\text{Cl}^-$ 的淌度增长幅度。结果是，$\text{Li}^+$ 的迁移数 $t_{\text{Li}^+}$ 会随温度升高而增大。这一现象深刻地揭示了离子溶剂化结构的动态本质。

### 浓度依赖性与进阶概念

#### 弱电解质的迁移数

对于强电解质，在稀溶液范围内，离子淌度变化不大，迁移数近似为常数。但对于弱电解质，情况则更为复杂。以醋酸（$\text{CH}_3\text{COOH}$）水溶液为例。[@problem_id:1599701]

在浓度较高的醋酸溶液中，电离产生的 $\text{H}^+$ 和醋酸根离子 $\text{CH}_3\text{COO}^-$ 是主要的载流子。此时，$\text{H}^+$ 的迁移数约为 $t_{\text{H}^+} \approx u_{\text{H}^+} / (u_{\text{H}^+} + u_{\text{CH}_3\text{COO}^-})$。由于 $u_{\text{H}^+}$ 远大于 $u_{\text{CH}_3\text{COO}^-}$，这是一个较高的值。

然而，当溶液被无限稀释时，醋酸的电离变得微不足道，而水的自偶电离（$\text{H}_2\text{O} \rightleftharpoons \text{H}^+ + \text{OH}^-$）成为离子的主要来源。此时的溶液行为接近于纯水。$\text{H}^+$ 的迁移数趋近于一个由 $\text{H}^+$ 和 $\text{OH}^-$ 决定的极限值：$t_{\text{H}^+} \to u_{\text{H}^+} / (u_{\text{H}^+} + u_{\text{OH}^-})$。由于氢氧根离子的淌度 $u_{\text{OH}^-}$ 远大于醋酸根离子的淌度 $u_{\text{CH}_3\text{COO}^-}$，分母变大，导致极限稀释时的 $t_{\text{H}^+}$ 值反而低于在有限浓度时的值。因此，随着醋酸溶液的稀释，$\text{H}^+$ 的迁移数会从一个较高的值逐渐降低，并趋近于一个较低的非零常数。

#### 真实迁移数与表观迁移数

我们之前的讨论都 implicitly 假设溶剂是静止的参考系。然而，在现实中，溶剂化离子在迁移时会“拖拽”一部分溶剂分子一起运动，导致溶剂本身相对于实验装置（例如，希托夫池的隔膜）发生净流动。[@problem_id:1599697]

这就引出了两种迁移数的定义：
1.  **表观迁移数 ($t_{app}$)**：这是在以实验室固定设备为参考系时测得的迁移数，例如通过经典的希托夫法测量电极区浓度变化计算得到。它反映的是离子相对于池壁的净迁移。
2.  **真实迁移数 ($t_{true}$)**：这是以（平均）静止的溶剂为参考系定义的迁移数。它代表了离子在溶剂中真正的相对运动对电流的贡献，是一个更基本的物理量。

为了从实验上区分这二者，可以在溶液中加入一种不导电、不参与电极反应且不随电场迁移的惰性示踪剂（如尿素）。通过测量电解前后示踪剂浓度的变化，可以计算出溶剂本身被离子拖拽而发生的净迁移量。[@problem_id:1599697] 对表观迁移数进行溶剂迁移校正后，即可得到真实迁移数。这一概念的引入揭示了离子输运过程的深层复杂性，即离子迁移与溶剂迁移是耦合在一起的。
