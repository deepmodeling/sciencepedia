## 引言
从橡皮筋的拉伸到熔融塑料的流动，理解软材料如何变形是物理学和工程学中的一个核心挑战。虽然简单的线性关系可以描述小变形，但当材料被大幅拉伸、剪切和扭曲时，这些关系便不再适用。这就产生了一个关键的知识空白：我们如何以一种具有物理意义、并能预测由此产生的[内力](@entry_id:167605)或应力的方式，来数学地描述大的、复杂的变形？本文通过引入[连续介质力学](@entry_id:155125)中的一个基本工具——Finger张量，来解答这个问题。

在接下来的章节中，我们将踏上一段理解这一强大概念的旅程。首先，在“原理与机制”一章中，我们将探讨Finger张量的数学基础，揭示它是如何从变形梯度中推导出来的，以及为何其独特的性质使其成为理想的、客观的[应变度量](@entry_id:755495)。然后，在“应用与跨学科联系”一章中，我们将看到这个抽象的张量如何成为一个实用的工具，构成了解释[粘弹性材料](@entry_id:194223)奇特行为的[本构模型](@entry_id:174726)的核心，从而架起了从分子理论到工业工程的桥梁。

## 原理与机制

想象一下，你拿一块面团，在其表面标记一个完美的方形网格。现在，你开始揉捏它。你拉伸它，扭曲它，把它压平。整齐的方格[网格变形](@entry_id:751902)为由歪斜和拉伸的平行四边形组成的疯狂拼布。我们如何才能以一种精确的数学方式来描述这种复杂的转变？这是[连续介质力学](@entry_id:155125)的基本问题，其答案将我们带入一个美丽的张量世界，而Finger张量在其中扮演着主角。

### 捕捉形状变化：变形梯度

我们的第一个任务是创建一个“地图”，告诉我们面团中的每一个点移动到了哪里。我们称初始的、未变形的状态为**参考构型**，其中任意一点的位置为$\mathbf{X}$。最终的、变形后的状态是**当前构型**，同一点的新位置是$\mathbf{x}$。那么，变形就是一个函数$\mathbf{x}(\mathbf{X})$。

为了理解某个点周围局部发生的情况，我们可以放大我们最初的微小方格中的一个。我们将这个方格的一条边表示为一个微小矢量，$d\mathbf{X}$。揉捏之后，这个矢量变成一个新的微小矢量$d\mathbf{x}$。这两个“之前”和“之后”的矢量之间的关系是关键。对于小矢量，这种关系是线性的，我们可以用一个矩阵，或者更普遍地，用一个张量来表示它，我们称之为**变形梯度**，$\mathbf{F}$。

$$
d\mathbf{x} = \mathbf{F} d\mathbf{X}
$$

变形梯度$\mathbf{F}$是一个局部字典。它接收任何来自原始面团的微小矢量，并告诉你它在揉捏后的面团中变成了什么。它的分量就是[偏导数](@entry_id:146280)$F_{ij} = \frac{\partial x_i}{\partial X_j}$。这个张量包含了关于局部变形的*所有*信息：拉伸、剪切和旋转。

### 旋转带来的麻烦：对客观性的追求

在这里，我们遇到了一个微妙而深刻的问题。变形梯度$\mathbf{F}$无所不知，但它知道得*太多了*。想象一下，你拿起你的面团，但不是揉捏它，而只是简单地将它捡起并旋转。面团本身根本没有应变——其内部任意两点之间的距离没有改变。不应该产生应力。然而，每个点的矢量$\mathbf{x}$都改变了，变形梯度$\mathbf{F}$也改变了！在这种情况下，$\mathbf{F}$将只是一个[旋转张量](@entry_id:191990)$\mathbf{Q}$。

如果我们的应力计算物理定律直接依赖于$\mathbf{F}$，那么它们会仅因为旋转材料就预测出应力。这会很荒谬。这就像说，如果你从一个旋转的木马上看汽车的引擎，引擎会感受到更大的应力。我们的物理定律必须独立于观察者的参考系；它们必须是**客观的**。这个被称为**物质坐标系无关性**的原理要求，我们的[应变度量](@entry_id:755495)应该忽略纯[刚体](@entry_id:1131033)旋转，只响应真实的变形——即那些真正使材料产生应变的拉伸和剪切。

### Finger张量：一种纯粹的[应变度量](@entry_id:755495)

那么，我们如何才能从$\mathbf{F}$中精确地移除旋转信息，只保留纯粹的拉伸呢？一个绝妙的数学技巧应运而生。任何变形都可以被看作是一个纯拉伸后跟一个纯旋转（反之亦然）。这就是著名的$\mathbf{F}$的**极分解**，很像用极坐标形式表示一个复数。我们可以写出$\mathbf{F} = \mathbf{V}\mathbf{R}$，其中$\mathbf{R}$是一个[旋转张量](@entry_id:191990)，$\mathbf{V}$是一个称为左[拉伸张量](@entry_id:193200)的[对称张量](@entry_id:148092)，它代表了变形中纯粹的拉伸和剪切部分。

为了分离出拉伸，我们可以计算$\mathbf{F}\mathbf{F}^T$这个量。看看会发生什么：

$$
\mathbf{B} = \mathbf{F}\mathbf{F}^T = (\mathbf{V}\mathbf{R})(\mathbf{V}\mathbf{R})^T = \mathbf{V}\mathbf{R}\mathbf{R}^T\mathbf{V}^T
$$

由于$\mathbf{R}$是一个[旋转张量](@entry_id:191990)，它的[转置](@entry_id:142115)是它的逆，即$\mathbf{R}\mathbf{R}^T = \mathbf{I}$，单位张量。方程神奇地简化为：

$$
\mathbf{B} = \mathbf{V}\mathbf{I}\mathbf{V}^T = \mathbf{V}^2
$$

这个张量$\mathbf{B}$就是**[左柯西-格林张量](@entry_id:186163)**，也被广泛称为**Finger张量**。请注意旋转$\mathbf{R}$是如何完全消失的！Finger张量$\mathbf{B}$只依赖于[拉伸张量](@entry_id:193200)的平方。它是变形的一种纯粹、客观的度量，捕捉了材料在其最终的、当前构型中是如何被应变的。

为了感受一下$\mathbf{B}$告诉我们什么，考虑一个简单的“双轴拉伸”变形，我们将一个块体在$x_1$方向上拉伸$k$倍，并在$x_2$方向上压缩$1/k$倍以保持体积不变。变形梯度是一个简单的[对角矩阵](@entry_id:637782)：

$$
\mathbf{F} = \begin{pmatrix} k  0  0 \\ 0  \frac{1}{k}  0 \\ 0  0  1 \end{pmatrix}
$$

于是Finger张量为：

$$
\mathbf{B} = \mathbf{F}\mathbf{F}^T = \begin{pmatrix} k  0  0 \\ 0  \frac{1}{k}  0 \\ 0  0  1 \end{pmatrix} \begin{pmatrix} k  0  0 \\ 0  \frac{1}{k}  0 \\ 0  0  1 \end{pmatrix} = \begin{pmatrix} k^2  0  0 \\ 0  \frac{1}{k^2}  0 \\ 0  0  1 \end{pmatrix}
$$

物理意义非常清晰：$\mathbf{B}$的对角元素是沿坐标轴的拉伸比的平方。如果在参考状态下有一个长度为$L_0$的微小线段指向$x_1$轴，它的新长度的平方将是$L^2 = k^2 L_0^2$。Finger张量直接量化了这种拉伸。

当然，变形很少如此整齐地与我们的坐标轴对齐。但其基本含义通过$\mathbf{B}$的**不变量**得以保留，它们是其分量的组合，无论我们如何定向坐标系，其值都保持不变。最重要的是第一不变量，$I_1 = \text{tr}(\mathbf{B})$，即[张量的迹](@entry_id:190669)。可以证明，$I_1 = \lambda_1^2 + \lambda_2^2 + \lambda_3^2$，其中$\lambda_i$是主拉伸——沿三个相互垂直的最大拉伸方向的拉伸比。这个单一的数字为我们提供了材料总平方伸长率的基本度量。

### 运动中的张量：描述流动

到目前为止，我们比较了一个“之前”的状态和一个“之后”的状态。但是对于流体，比如旋转的河流或被挤出成纤维的聚合物，情况又如何呢？变形是连续不断变化的。Finger张量也为描述这种情况提供了完美的语言。

让我们想象一个简单的流体流动，比如在吐司上抹蜂蜜。顶层移动最快，而粘在吐司上的那层则根本不动。这就是**[简单剪切流](@entry_id:1131665)**，其速度场由$\mathbf{v} = \dot{\gamma} x_2 \mathbf{e}_1$给出，其中$\dot{\gamma}$是恒定的剪切速率。如果我们从时间$t=0$开始追踪变形，我们可以计算出作为时间函数的Finger张量：

$$
\mathbf{B}(t) = \begin{pmatrix} 1 + \dot{\gamma}^{2} t^{2}  \dot{\gamma} t  0 \\ \dot{\gamma} t  1  0 \\ 0  0  1 \end{pmatrix}
$$

这个矩阵是流动的一本故事书。非对角项$\dot{\gamma} t$告诉我们剪切量在不断增加。但请看左上角的分量，$B_{11} = 1 + \dot{\gamma}^{2} t^{2}$。它表明流体单元不仅被剪切，它还在流动方向上被拉伸，并且这种拉伸随时间呈二次方增长！这是[剪切流](@entry_id:266817)体的一个显著的、非直观的结果，而Finger张量完美地捕捉了它。

为了描述这种连续的演化，我们需要一种“流动应变的微积分”。我们可以问：当$\mathbf{B}$随着流体一起运动时，它如何从一个时刻变化到下一个时刻？答案是一个优美的运动学恒等式，它将$\mathbf{B}$的[物质时间导数](@entry_id:190892)与[速度梯度张量](@entry_id:270928)$\mathbf{L} = \nabla\mathbf{v}$联系起来：

$$
\frac{D\mathbf{B}}{Dt} = \mathbf{L}\mathbf{B} + \mathbf{B}\mathbf{L}^T
$$

这个表达式意味着$\mathbf{B}$的**上随体时间导数**为零，它是许多复杂流体模型的核心。它精确地告诉我们流体包裹中的应变如何因局部速度场而演化。值得注意的是，其逆张量$\mathbf{B}^{-1}$具有一个互补的性质：其**下随体时间导数**恰好为零。这意味着，从某个数学视角（一个随流体拉伸和剪切的坐标系）来看，张量$\mathbf{B}^{-1}$是一个[守恒量](@entry_id:161475)。$\mathbf{B}$与$\mathbf{B}^{-1}$之间这种优雅的对偶性是现代[流变学](@entry_id:138671)的基石。

### 通往现实的桥梁：应力与[本构定律](@entry_id:178936)

我们为什么要费这么大劲来定义一个忽略旋转并测量平方拉伸的张量？最终原因是为了预测**应力**。将材料聚合在一起、并在我们使其变形时感受到的阻力，是由[应力张量](@entry_id:148973)$\boldsymbol{\sigma}$描述的。连接应力与变形的规则被称为**本构方程**——它们定义了材料的力学特性。

对于像弹簧这样的简单弹性固体，[应力与应变](@entry_id:137374)成正比。但对于像橡胶、生物组织或熔融塑料这样的复杂材料，情况要复杂得多。这些材料有“记忆”；它们当前的应力取决于其整个变形历史。Finger张量是实现这一点的完美工具。因为它具有客观性并且存在于当前构型中（就像[应力张量](@entry_id:148973)$\boldsymbol{\sigma}$一样），它为运动和力之间提供了理想的联系。

像**Kaye-Bernstein-Kearsley-Zapas (K-BKZ) 模型**这样的模型提出，当前的应力是所有过去时刻Finger张量的加权平均。一个简化的形式如下：

$$
\boldsymbol{\sigma}(t) = \int_{-\infty}^{t} m(t-s) \mathbf{B}(t,s) ds
$$

这里，$m(t-s)$是一个“记忆函数”，它对近期的变形赋予更大的权重，而$\mathbf{B}(t,s)$是测量从过去时间$s$到当前时间$t$的变形的Finger张量。这个优雅的方程说：“你现在感受到的应力是过去所有应变回响的总和。”正是通过在[本构定律](@entry_id:178936)中的这个核心作用，Finger张量充当了从抽象的变形几何到可触摸的力与材料响应现实之间的桥梁，构成了一个更宏大、相互关联的[张量力](@entry_id:161961)学织锦的统一部分[@problem_-id:1549127]。
