## 应用与跨学科联系

在理解了[脉冲宽度调制](@entry_id:262667)的原理之后，我们现在可以踏上一段旅程，去看看这个绝妙而简单的想法将我们带向何方。它几乎无处不在！PWM 的美妙之处在于，它并非针对某个特定问题的偏门技巧；它是一个基本概念，用于连接数字计算机离散的、非黑即白的世界与物理世界连续的、充满灰色地带的现实。它集翻译器、执行器和一种语言于一身。

### 从数字比特到模拟世界

从本质上讲，PWM 是一种通过控制时间来伪造模拟值的方法。一个数字系统无法轻易地从一个 5 伏的电源产生出，比如说，2.5 伏的电压。但它可以轻易地将那个 5 伏电源精确地开启一半的时间。如果它这样做得足够快，被驱动的系统——无论是电机、加热器还是灯——只对*平均*效果做出响应，而这个效果恰好是 2.5 伏。魔力就在于这个平均值。

这种[数模转换](@entry_id:260780)的实现方式可以惊人地简单。你所需要的只是一个重复计数的计数器和一个比较器。一个代表我们期望“电平”的数字被送入比较器。只要计数器的值小于我们的电平，输出就是“开”；一旦超过该电平，输出就变为“关”。通过改变那个数字，我们直接控制了[占空比](@entry_id:199172)，从而控制了平均输出电压 。

这个控制平均电压的简单行为催生了大量的应用。考虑一个简单的直流电机。它产生的扭矩与流经它的电流成正比。通过向它馈送一个 PWM 信号，我们控制了平均电流。电机自身的惯性平滑了快速的脉冲，因此它对这个平均值的响应就如同对一个稳定、连续的力一样。用几行代码和一个简单的电路，我们就能以数字精度命令电机以任何速度旋转或施加任何扭矩 。这就是从装配线上的工业机器人到你相机中的对焦镜头等一切事物获得运动的原理。

现在，让我们把注意力从运动转向光。我们可以用同样的方式调暗一个[发光二极管](@entry_id:158696)（LED），即通过[占空比](@entry_id:199172)控制平均电流。将[占空比](@entry_id:199172)设为 0.25，你就能得到四分之一的亮度，对吗？不完全是！在这里，我们偶然发现了一个有趣的跨学科联系：原理是可行的，但*感知*却很棘手。我们的眼睛对亮度的感知并[非线性](@entry_id:637147)的。一个处于其最大物理亮度 0.5 的光源，看起来要比达到最大亮度的一半亮得多。人类的感知大致是对数的。因此，为了创造一个对人来说感觉平滑且线性的调光器，工程师必须对[占空比](@entry_id:199172)指令进行预失真处理。一个期望的感知亮度 $r$ 需要一个与 $r^{\gamma}$ 成正比的[占空比](@entry_id:199172)，其中 $\gamma$（伽马）是一个与眼睛响应相关的常数。这种“伽马校正”是一个绝佳的例子，说明了工程设计为何必须常常考虑人类生物学的特性 。

### 现代电子设备中看不见的心跳

当 PWM 被置于一个反馈回路中时，它的威力才真正闪耀。在这里，它不再仅仅是执行一个预定的命令；它变成了控制系统用来主动对抗干扰、维持期望状态的“肌肉”。

也许最普遍且最被低估的应用就是[开关模式电源](@entry_id:1132724)（SMPS）。几乎每一件现代电子设备，从你的笔记本电脑充电器到支撑互联网的巨型服务器集群，都由 SMPS 供电。这些设备将一个不稳定的输入电压（比如来自墙壁插座的可变电压）转换为精密微芯片所需的稳定、精确的输出电压。这个过程的核心是一个 PWM 控制器。它持续测量输出电压。如果电压哪怕只是稍微下降了一点（也许是因为你的处理器刚开始一项繁重的计算），控制器会立即增加一个微型高速开关的[占空比](@entry_id:199172)，以输送更多功率。如果电压过冲，它就减小[占空比](@entry_id:199172)。这一切每秒发生数千甚至数百万次，从而从一个不稳定的源头创造出一个极其稳定的输出 。

通常，为了安全起见，这个控制回路必须跨越一个隔离屏障，以确保高压输入端和你接触的低压输出端之间没有直接的电气连接。反馈信号——一个对输出电压的度量——被转换成电流，驱动[光耦合器](@entry_id:1129186)中的 LED。这个 LED 发出的光穿过屏障，被一个光电晶体管接收，该晶体管将相应的电流注入到初级侧的 PWM 控制器中以调整[占空比](@entry_id:199172)。整个方案是一种并联-并联反馈的形式，它在保证安全的同时优雅地维持了控制 。

### 作为一种语言的 PWM

我们已经看到 PWM 如何被用来命令物理世界。但以一种美妙的对称性，它也可以被用来*描述*物理世界。我们可以反转这个过程，用 PWM 将一个模拟测量值编码成[数字信号](@entry_id:188520)。想象一个测量温度的传感器。它不必输出一个易受噪声影响的脆弱模拟电压，而是可以输出一个[占空比](@entry_id:199172)与温度成正比的 PWM 信号。这个由 1 和 0 组成的流要健壮得多；噪声更难将一个 1 翻转成 0，而不是破坏一个精确的电压电平。

我们如何解读这种语言？一种方法是简单地让信号通过一个低通滤波器来恢复平均电压。一种更优雅的数字方法涉及异步采样。如果你在随机的时间间隔采样 PWM 信号的状态，捕捉到它处于“高”状态的概率恰好等于其[占空比](@entry_id:199172)。一个由不相关时钟触发的简单 D [锁存器](@entry_id:167607)就可以充当这样的采样器。[锁存器](@entry_id:167607)输出的长期平均值将收敛于[占空比](@entry_id:199172)，从而揭示出编码的测量值 。

PWM 作为通信信道的这个概念在高噪声环境中至关重要。例如，要在一个存在巨大且危险电压差的系统中测量电压——比如电动汽车的电池管理系统——我们可以将测量值编码为 PWM 信号，并通过一个数字隔离器发送出去。接收端随后解码[占空比](@entry_id:199172)以获得测量值。然而，我们必须留意现实世界的不完美之处。如果隔离器的上升沿和下降沿的传播延迟不同，[占空比](@entry_id:199172)在跨越屏障时就会失真，从而在我们的测量中引入一个必须被理解和补偿的系统性误差 。

### 不完美之处与交响乐

“平均值”的概念是一个强大的简化，但它终究是一种简化。底层的髙频切换始终存在，有时它会带来后果。当我们用 PWM 驱动电机时，平均转矩给了我们想要的平滑运动，但电流的快速开关仍然会以开关频率产生微小的转矩脉冲。这可能导致可闻的啸叫声或一种称为“[转矩脉动](@entry_id:1133255)”的细微振动。为了分析这一点，我们可以使用[傅里叶分析](@entry_id:137640)这个强大的工具。PWM 的方波特性可以分解为一个开关频率下的基波正弦波，以及一系列更高频率的[谐波](@entry_id:181533)。通过理解系统的[频率响应](@entry_id:183149)——即它对不同频率的“反应”程度——我们可以预测由此产生的脉动幅度，并选择一个足够高的开关频率，以便被电机自身的机械惯性滤除 。

这种与频率的权衡在照明领域再次出现。为了让一个 PWM 调光的灯看起来稳定，开关频率必须高于我们眼睛的“刷新率”，即所谓的临界闪烁融合（CFF）频率。低于这个频率，我们会感知到恼人的闪烁。有趣的是，CFF 并非一个固定的数字；它取决于光本身的亮度！Ferry-Porter 定律告诉我们，CFF 随亮度的对数增加而增加。这意味着，当我们使用 PWM 调暗一盏灯时（通过降低[占空比](@entry_id:199172)），避免闪烁所需的频率实际上会降低。这是又一个例子，说明一个电子系统的设计与人类感知科学是如何深度交织在一起的 。

### 构建世界的工具

在信息物理系统和[数字孪生](@entry_id:171650)的现代纪元，PWM 已经确立了其作为工程师大师工具箱中基本工具的地位。在为像汽车或飞机这样的复杂机器开发新的控制系统时，工程师们越来越依赖硬件在环（HIL）仿真。一台实时计算机模拟机器的物理过程，并且它必须与正在测试的实际控制器进行通信。这个模拟器必须生成控制器期望看到的所有传感器信号，并解释控制器产生的所有执行器命令。

为此，HIL 系统使用了一个 I/O 的“管弦乐队”。它使用[数模转换器](@entry_id:267281)（DAC）来创建平滑、真正的模拟信号。它使用通用输入/输出（GPIO）引脚来处理像限位开关这样的简单开关信号。并且它使用专用的定时器硬件来进行 PWM 操作——既用于生成像[旋转编码器](@entry_id:164698)这样的信号[脉冲序列](@entry_id:1132157)，也用于精确测量来自控制器的执行器命令的[占空比](@entry_id:199172)。在这种背景下，PWM 不是一项孤立的技术，而是在真实物理硬件与其模拟数字副本之间接口处使用的词汇的关键部分 。

从调暗一盏灯到控制一个机器人，从为智能手机供电到构建喷气发动机的数字孪生，切割时间的简单想法被证明是现代科学与工程中最通用、最强大的概念之一。
