## 引言
在我们这个联系日益紧密的世界中，物理系统的数字复制品，即[数字孪生](@entry_id:171650)（Digital Twins），必须精确地反映现实，才能安全有效地运行。这个镜像过程依赖于估计：从传感器数据流中推断出系统的真实状态。虽然像卡尔曼滤波器（Kalman filter）这样的经典工具擅长滤除随机的环境噪声，但它们在面对一种更狡猾的威胁——对传感器输入的蓄意恶意攻击时，往往毫无防备。本文旨在填补在针对统计噪声的设计与针对对抗性欺骗的工程实现之间的关键知识空白。文章全面概述了如何构建能够在敌对环境中以怀疑的眼光审视数据并保持其完整性的估计器。

在接下来的章节中，我们将踏上深入安全估计核心的旅程。在“原理与机制”一章中，我们将剖析标准方法为何会失效，并揭示弹性的基本概念，包括冗余、[稀疏性](@entry_id:136793)和博弈论。随后，“应用与跨学科联系”一章将展示这些原理如何转化为实际解决方案，涵盖了从具有安全意识的物理设计和[鲁棒算法](@entry_id:145345)，到可实现目标的根本性信息论限制。

## 原理与机制

要构建一个能够独立思考的系统，尤其是一个能够镜像复杂物理过程的系统，我们必须首先教会它如何“看”。但“看”意味着什么呢？对于[数字孪生](@entry_id:171650)而言，“看”就是估计——接收大量含噪声、不完整的数据，并从中推断出其所代表的系统的真实潜在状态。这是一个经典问题，我们拥有像著名的卡尔曼滤波器（Kalman filter）这样的优秀工具来解决它。这些工具是处理自然界中随机、统计性模糊信号的大师。

但在信息物理世界中，我们面临着一种不同的不确定性，它比纯粹的随机性更为狡猾。我们面对的是一个对手。对系统传感器的攻击不像[热噪声](@entry_id:139193)那样温和。它是一个精心策划的、蓄意的谎言。我们探索抗攻击估计的旅程，始于理解这种深刻的差异。

### 不可预测与恶意：噪声与攻击

想象一下，你正试图在拥挤的人群中走一条直线。推挤和碰撞来自四面八方。有时它们把你推向左边，有时推向右边。但平均而言，这些随机的干扰会相互抵消。一个好的策略——比如顺着推力倾斜身体以保持平衡——可以过滤掉这种混乱，让你保持在正确的路线上。这就是标准估计器处理**过程噪声**（$w_k$）和**测量噪声**（$v_k$）的方式。我们对这种噪声进行统计建模：它没有优先方向（零均值），且每次推挤都与上一次无关（即“[白噪声](@entry_id:145248)”）。我们可以用已知的协方差来表征其典型幅度。

现在，想象一下，在这群人中，有一个人正积极地试图把你推离路线。他们不是随机的。他们观察你的一举一动，并在恰当的时机施加一个蓄意的力，以达到他们的目的。这就是**[对抗性攻击](@entry_id:635501)**（$a_k$ 或 $b_k$）。将这个对手仅仅建模为另一个随机噪声源将是一个严重的错误。对手的信号不受统计平均值的约束。它可能是一个恒定的、有偏的推力（**偏置注入攻击**），也可能是一个复杂的信号，旨在利用你平衡策略的内在逻辑 。

要构建一个弹性系统，我们不能将恶意对手仅仅视为另一个随机噪声源。我们必须将其视为博弈中的一个智能玩家，其行动不受概率限制，而是受其资源和对系统知识的限制。弹性的关键在于发现并利用随机性的可预测性与智能攻击的结构性之间的根本差异。

### 信任的脆弱性：为什么标准估计器会失效

我们的第一反应可能是部署一个标准的、高性能的估计器，看看它是否能抵御攻击。这些估计器的工作原理是将传入的测量值与物理模型的预测值进行比较。测量值与预测值之间的差异称为**残差**（residual）或**新息**（innovation）。

#### 泄密的残差与机器中的幽灵

在正常情况下，当没有攻击（$a_k=0$）时，残差仅仅是随机[测量噪声](@entry_id:275238)的反映。对于一个设计良好的卡尔曼滤波器，这个残差序列是零均值的，并具有一个可计算的[协方差矩阵](@entry_id:139155)，我们称之为 $S_k$。这一见解非常强大。我们可以构建一个统计检验。例如，量 $J_k = r_k^{\top} S_k^{-1} r_k$ 服从一个已知的分布——卡方（$\chi^2$）分布。我们可以设定一个阈值：如果 $J_k$ 变得过大，那么它极不可能仅仅来自噪声，我们就会发出警报。这很可能意味着检测到了攻击！。

但如果攻击者很聪明呢？攻击者了解我们的系统。他们知道将隐藏状态 $x_k$ 与测量值 $y_k$ 联系起来的测量矩阵 $C$。有没有可能构造一个攻击向量 $a_k$ 来欺骗我们的残差检测器？

答案是响亮而又令人不安的“是”。考虑在没有噪声的情况下的残差结构：$r_k = y_k - C\hat{x}_k$。如果将攻击 $a_k$ 添加到测量中，新的测量值将是 $y_k^{\text{att}} = y_k + a_k = C x_k + a_k$。残差变为 $r_k^{\text{att}} = C x_k + a_k - C\hat{x}_k$。一个简单的检测器只是检查测量值是否“看起来正常”。为了保持[隐蔽](@entry_id:196364)，攻击者必须注入一个信号 $a_k$，使其看起来像是可能来自一个合法的状态。从几何角度看，这意味着攻击向量 $a_k$ 必须位于测量矩阵 $C$ 的[列空间](@entry_id:156444)中。如果攻击者选择 $a_k = C d$（其中 $d$ 为某个向量），那么测量值就变成 $y_k^{\text{att}} = C x_k + C d = C (x_k + d)$。估计器看到的测量值与另一个状态 $(x_k+d)$ 完全一致。这种攻击与真实系统的变化无法区分。它变成了机器中的幽灵，在不留痕迹的情况下操纵系统所感知的现实 。

#### 仅有稳定性是不够的

这引出了一个至关重要的见解。在控制理论中，我们努力设计稳定的观测器，比如 Luenberger 观测器。稳定性意味着，如果我们在状态的初始猜测上犯了一个小错误，这个错误会随着时间的推移自然地缩小并消失。由诸如 $(A-LC)$ 这样的矩阵支配的误差动态是稳定的。但是，当存在隐蔽攻击时会发生什么？误差动态变为 $e_{k+1} = (A - L C) e_k - L a_k$。尽管 $(A-LC)$ 部分是稳定的，但攻击 $a_k$ 充当了一个持续的外部输入。如果攻击者注入一个恒定的、隐蔽的攻击，稳定的动态特性不会使误差消失。相反，误差将收敛到一个恒定的非零值——一个偏置。观测器将自信地报告一个错误的状态，而其自身的稳定性会阻止它进行自我校正 。这是一个深刻的教训：**稳定性并不意味着弹性**。一个只为抵御随机噪声而设计得稳定的系统，在面对一个坚决的对手时，可能会表现得极其脆弱。

### 弹性的基石：冗余的力量

如果单一的信息线索如此容易被破坏，那么通往弹性的道路必定在于编织一张更坚固的网。我们需要**冗余**。我们需要多种、独立的方式来观察系统，这样来自一个来源的谎言就可以被另一个来源的真相所揭穿。

#### 更多双眼睛：来自传感器的冗余

最直接的冗余形式是拥有比严格需要时更多的传感器。控制理论中的一个核心概念是**能观性**（observability）。如果一个系统通过随时间观察其输出，能够唯一地确定其内部状态，那么这个系统就是能观的。这通常通过检查一个特殊矩阵，即能观性矩阵 $\mathcal{O}$，是否具有满秩来判断。

现在，让我们将其与安全性联系起来。假设我们有一个具有 3 个状态和 3 个传感器的系统，并且它是能观的。如果攻击者入侵了一个传感器，实际上相当于移除了它，会发生什么？为了判断系统是否仍然具有弹性，我们可以构建一个新的测量矩阵 $C_{-S}$，其中移除了该传感器的对应行。然后我们构建一个新的能观性矩阵 $\mathcal{O}_{-S}$，并检查其秩。如果秩仍然是 3，那么系统仍然是能观的！我们从剩下的两个传感器中获得了足够的冗余信息，可以重构完整的状态，并且原则上可以识别出那个讲述不同故事的被入侵传感器 。这种承受一个（或几个）传感器损失的能力，是[系统弹性](@entry_id:1132834)的直接衡量标准。这不仅仅是关于拥有传感器；而是关于它们的测量值如何通过矩阵 $A$ 和 $C$ 在几何上与状态相关联。

#### 不可打破的规则：来自物理学的冗余

冗余不仅仅是增加更多的硬件。有时，最强大的冗余形式来自于我们已经拥有的东西：知识。物理世界受定律支配——能量守恒、质量守恒、运动学约束。这些定律是对系统变量的精确[等式约束](@entry_id:175290)。例如，我们可能知道对于任何有效的状态 $x_k$，一个像 $G x_k = h$ 这样的线性关系必须始终成立。

这个物理定律是一个“不变量”，是攻击者无法改变的基本事实。我们可以利用这一点。所有满足此约束的状态 $x_k$ 的集合，在更大的[状态空间](@entry_id:160914)内形成一个低维的仿射子空间。我们进行的任何测量都必须对应于该子空间内的一个状态。这一认识使我们能够构建一种特殊的残差。我们可以找到一个投影，它能消除任何与物理定律一致的信号。当我们对测量值应用这个投影时，任何幸存下来的部分*必然*来自违反了这些定律的东西——即噪声或攻击。

通过分析这个投影残差的统计特性，我们可以创建一个强大的检测器。如果攻击试图将系统的表观状态推出由物理学定义的约束流形之外，那么该攻击就是可检测的。这种方法巧妙地将我们对物理定律的抽象知识转化为一个具体、可计算的安全工具 。

### 数字时代的奥卡姆剃刀：稀疏性原理

我们已经确定冗余是关键。但在实践中我们如何使用它呢？当我们有很多传感器，而其中一些在说谎时，我们如何决定信任哪些传感器？答案来自一个美妙的原则，它结合了物理学、信息论和健康的常识。

#### 寻找最简单的解释

让我们做一个合理的假设：对手很强大，但并非无限强大。他们可以入侵一些传感器，但不是全部，至少不是一次性全部入侵。这就是**稀疏性假设**：攻击向量 $a_k$ 是稀疏的，意味着它的大多数分量为零。

现在，考虑估计器的工作。它看到一组测量值 $y_k$，并且它知道物理定律 $x_{k+1}=Ax_k+Bu_k$。测量值可能与定律不完全一致。为什么？可能是真实状态与模型之间存在巨大而复杂的偏差，或者……是少数几个传感器在说谎。哪种解释更可能呢？

[奥卡姆剃刀](@entry_id:142853)原则建议我们应倾向于最简单的解释。最简单的解释是那个忠于物理模型，并将差异归咎于*最少数量传感器*的解释。这种直觉可以被形式化为一个优化问题。我们寻找一个状态轨迹 $\{x_k\}$，它完全服从系统动态，同时最小化[残差向量](@entry_id:165091) $r_k = y_k - C x_k$ 中非零分量的数量。这等价于最小化所谓的残差的 $\ell_0$-范数：$\min \sum_k \|y_k - C x_k\|_0$ 。我们实际上是在寻找能使攻击看起来尽可能稀疏的状态轨迹。

#### 信任的代价：稀疏能观性

这种策略何时有效？仅仅拥有更多传感器是不够的。我们需要“正确类型”的冗余。我们需要系统在丢弃*任何*一小组传感器的测量值后仍然是能观的。对于一个最多攻击 $s$ 个传感器的对手，我们需要一个称为**$2s$-稀疏能观性**的条件。这个条件保证了对于任意两个不同的状态轨迹，它们的传感器输出之差不可能是稀疏的（具体来说，它不能在 $2s$ 或更少的传感器上非零）。这可以防止对手制造一个看起来像有效系统行为的“稀疏谎言”。如果系统具备此属性，$\ell_0$ 最小化保证能恢复唯一真实的状​​态，并将其与对手的稀疏操纵完美分离开来 。

### 为最坏情况设计：一场与对手的博弈

到目前为止，我们看到的方法都侧重于检测和拒绝攻击。但是，还有另一种同样深刻的弹性哲学：为最坏情况进行设计。如果我们假设对手始终存在并且总是在做最坏的打算，然后我们设计一个保证在这种持续攻击下表现尽可能好的估计器，会怎么样？这将问题构建成一个**极小化极大博弈**（minimax game）。

想象一场博弈，对手（最大化者）选择干扰和攻击（$w_k, a_k$）来最大化我们的估计误差 $e_k$。同时，我们（最小化者）选择我们的估计器来最小化这个相同的误差。这场博弈的解是一个鞍点——一个在面对最坏攻击时保证最小可能误差的估计器。这就是 **$H_\infty$ 估计**的核心思想 。

让我们考虑这个博弈的一个简单单步版本。假设我们的测量值为 $y_k = x_k + w_k + a_k$。一个朴素的估计器可能只是简单地信任测量值：$\hat{x}_k = y_k$。那么误差就是 $e_k = x_k - \hat{x}_k = -w_k - a_k$。对手的最佳策略是什么？为了最大化这个误差，他们会选择使干扰 $w_k$ 和攻击 $a_k$ 对齐。如果他们选择 $w_k = a_k$，误差变为 $e_k = -2a_k$。平方误差 $\|e_k\|^2$ 是平方攻击 $\|a_k\|^2$ 的四倍。这场博弈关注的是从对抗性输入到[估计误差](@entry_id:263890)的能量增益。在这个朴素的例子中，对手可以放大他们输入的能量。我们可以定义一个性能水平 $\gamma$，即最大可能的能量增益。只有当我们能找到一个使该增益有界的估计器时，博弈才存在有限解。对于我们的朴素估计器，我们可以证明其最坏情况下的增益是 $\gamma = \sqrt{2}$ 。

$H_\infty$ 设计的目标是找到一个估计器增益 $K$ 来最小化这个[最坏情况增益](@entry_id:262400) $\gamma$。这是一种极其悲观但又异常鲁棒的设计哲学。它提供了一个保证：无论对手做什么（在其[能量约束](@entry_id:1124454)内），[估计误差](@entry_id:263890)永远不会超过这个保证的界限。这是在敌对世界中性能的终极保证。

从区分噪声和攻击，到利用来自物理学和稀疏性的冗余，再到与最坏情况下的敌人进行博弈，抗攻击估计的原理揭示了控制理论、优化和信息科学之间丰富的相互作用。它们向我们展示了如何构建不仅能看，而且能以怀疑、智能和工程化的弹性来抵御欺骗的系统。
