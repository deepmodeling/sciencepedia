## 引言
牛顿-柯特斯（Newton-Cotes）求积公式是数值分析的基石之一，为近似计算定积分提供了一套直观且系统的方法。它基于一个简单而优雅的思想：用一个易于积分的多项式来代替复杂的被积函数。因其构造简单、易于实现，低阶的牛顿-柯特斯法则（如梯形法则和辛普森法则）在科学与工程的入门级计算中获得了广泛应用，成为许多从业者接触数值积分的第一个工具。

然而，对于从事高阶数值方法（如谱方法和间断伽辽金方法）研究的研究生和学者而言，仅仅掌握这些公式的定义是远远不够的。当我们将牛顿-柯特斯法则推广到高阶时，一个关键的知识鸿沟便显现出来：这些公式会表现出严重的数值不稳定性，从而限制了其在高精度计算中的应用。理解这种不稳定性的根源，并认识其对复杂数值格式（如能量稳定格式）的具体影响，是从基础用户向高级开发者转变的关键一步。

本文旨在填补这一鸿沟，为读者提供对牛顿-柯特斯公式的全面而深入的理解。
*   在“**原理与机制**”一章中，我们将从第一性原理出发，系统地构建牛顿-柯特斯公式，深入分析其代数精度，并着重揭示其高阶不稳定性（如负权重）的内在机制。
*   接着，“**应用与交叉学科联系**”一章将展示这些公式在物理、经济学乃至现代计算方法（如有限元和DG方法）中的实际角色，探讨它们在质量集中等技术中的巧妙应用以及在精确积分和处理非线性项时的局限性。
*   最后，“**动手实践**”部分提供了一系列精心设计的问题，引导读者通过实际推导和分析，亲身体验理论概念如何转化为实际的数值行为和稳定性问题。

通过这三章的学习，读者将不仅学会如何使用牛顿-柯特斯公式，更将深刻理解为何以及何时应当避免使用它们，并为转向更高性能的高斯求积等方法打下坚实的理论基础。让我们从其最基本的构造原理开始。

## 原理与机制

本章深入探讨牛顿-柯特斯（Newton-Cotes）求积公式的数学原理、内在机制及其在高阶谱方法和间断伽辽金（DG）方法中的具体应用和影响。我们将从第一性原理出发，系统构建这些求积法则，分析其关键性质（如代数精度），并着重揭示其在高阶应用中的固有局限性，如权重的不稳定性和负值现象。最终，我们将把这些理论性质与数值方法的实践，特别是能量稳定性分析，紧密联系起来。

### 牛顿-柯特斯求积公式的构建

所有牛顿-柯特斯公式都源于一个统一且简洁的思想：通过积分一个较为简单的函数——插值多项式——来近似原函数的积分。这种方法被称为**内插型求积 (interpolatory quadrature)**。

#### 闭式牛顿-柯特斯法则

闭式法则是指求积节点包含积分区间的两个端点。考虑在物理单元 $[a, b]$ 上对一个足够光滑的函数 $f(x)$ 进行积分。为了构造一个 $n+1$ 点的闭式牛顿-柯特斯法则，我们首先在该区间上选择一组**等距节点 (equispaced nodes)**。

具体而言，我们将区间 $[a, b]$ 分成 $n$ 个等长子区间，每个子区间的长度为 $h = (b-a)/n$。这样就得到了 $n+1$ 个节点：
$x_j = a + j h, \quad j = 0, 1, \dots, n$
这些节点包括了区间的两个端点 $x_0 = a$ 和 $x_n = b$。

下一步，我们构造一个唯一的、次数最高为 $n$ 的多项式 $p_n(x)$，它在这些节点上与函数 $f(x)$ 的值相等，即满足插值条件 $p_n(x_j) = f(x_j)$。利用**拉格朗日基多项式 (Lagrange basis polynomials)** $\ell_j(x)$，这个插值多项式可以被显式地写为：
$p_n(x) = \sum_{j=0}^{n} f(x_j) \ell_j(x)$
其中，每个拉格朗日基函数 $\ell_j(x)$ 都是一个 $n$ 次多项式，并具有性质 $\ell_j(x_i) = \delta_{ij}$（$\delta_{ij}$ 为克罗内克符号）。

牛顿-柯特斯求积公式的核心思想就是用 $p_n(x)$ 的积分来近似 $f(x)$ 的积分：
$\int_a^b f(x) \,dx \approx \int_a^b p_n(x) \,dx = \int_a^b \left( \sum_{j=0}^{n} f(x_j) \ell_j(x) \right) dx$

利用积分的线性性质，我们将求和符号移到积分之外：
$\int_a^b f(x) \,dx \approx \sum_{j=0}^{n} f(x_j) \left( \int_a^b \ell_j(x) \,dx \right)$

这就导出了一个标准的求积公式形式 $\sum_{j=0}^{n} w_j f(x_j)$。其中，**权重 (weights)** $w_j$ 被定义为对应拉格朗日基函数的积分：
$w_j = \int_a^b \ell_j(x) \,dx$

这个定义清晰地表明，权重 $w_j$ 仅依赖于节点的分布和积分区间，而与被积函数 $f(x)$ 无关。这正是数值求积公式的基本特征。[@problem_id:3401955]

在有限元和谱方法的实践中，为了计算的标准化和代码的复用性，通常会将任意物理区间 $[a, b]$ 上的计算通过一个仿射变换映射到**参考单元 (reference element)**，通常是 $[-1, 1]$。设 $x(\xi) = \frac{b-a}{2}\xi + \frac{a+b}{2}$，则 $dx = \frac{b-a}{2}d\xi$。权重 $w_j$ 的计算也随之转换到参考单元上进行：
$w_j = \int_{-1}^1 \ell_j(x(\xi)) \frac{b-a}{2} \,d\xi = \frac{b-a}{2} \int_{-1}^1 \hat{\ell}_j(\xi) \,d\xi$
其中 $\hat{\ell}_j(\xi)$ 是在参考单元 $[-1, 1]$ 上的等距节点 $\xi_j = -1 + 2j/n$ 上定义的拉格朗日基函数。[@problem_id:3401955]

为了从第一性原理推导权重的解析表达式，我们可以选择一个更便于代数计算的参考坐标系。例如，将物理节点 $x_j = a+jh$ 映射到整数节点 $\xi_j = j$（$j=0, \dots, n$），积分区间相应地变为 $[0, n]$。通过变量替换 $x(\xi) = a + \xi h$，我们有 $dx = h\,d\xi = \frac{b-a}{n}d\xi$。在该坐标系下，拉格朗日基函数 $\hat{\ell}_i(\xi)$ 变为：
$\hat{\ell}_i(\xi) = \prod_{j=0, j \neq i}^{n} \frac{\xi - j}{i - j}$
权重的表达式 $w_i = \int_a^b \ell_i(x) \,dx$ 经过变换后为：
$w_i = \frac{b-a}{n} \int_0^n \hat{\ell}_i(\xi) \,d\xi = \frac{b-a}{n} \int_0^n \left( \prod_{j=0, j \neq i}^{n} \frac{\xi - j}{i - j} \right) d\xi$
分母是一个常数，可以提到积分号外。经过仔细计算分母的乘积 $\prod_{j \neq i}(i-j) = i! (-1)^{n-i} (n-i)!$，我们得到权重的精确解析表达式：
$w_i = \frac{b-a}{n} \frac{(-1)^{n-i}}{i!(n-i)!} \int_0^n \left( \prod_{j=0, j\neq i}^n (\xi-j) \right) d\xi$
这个公式精确地刻画了权重如何依赖于区间长度 $(b-a)$、节点总数 $n+1$ 以及节点索引 $i$。[@problem_id:3401950]

#### 开式牛顿-柯特斯法则

与闭式法则相对的是**开式牛顿-柯特斯法则 (open Newton-Cotes rules)**，其求积节点全部位于积分区间的内部，不包括端点。为了在 $[a,b]$ 上布置 $m$ 个内部等距节点，我们将区间分成 $m+1$ 个等长子区间，步长为 $h = \frac{b-a}{m+1}$。节点取为：
$x_i = a + (i+1)h, \quad i = 0, 1, \dots, m-1$
权重的构造原理与闭式法则完全相同：对基于这 $m$ 个内部节点构造的 $m-1$ 次拉格朗日基函数 $\ell_i(x)$ 进行积分，即 $w_i = \int_a^b \ell_i(x) \,dx$。[@problem_id:3402003]

### 关键性质：代数精度

一个求积公式的**代数精度 (algebraic degree of precision)** 是指该公式能够精确积分的最高多项式次数。若一个公式对所有次数不超过 $m$ 的多项式都能给出精确积分值，但至少存在一个 $m+1$ 次多项式使其积分不精确，那么该公式的代数精度就是 $m$。

根据牛顿-柯特斯公式的构造方式，它通过积分一个 $n$ 次插值多项式来近似原函数积分。如果被积函数 $f(x)$ 本身就是一个次数不超过 $n$ 的多项式 $p(x)$，那么其自身的 $n$ 次插值多项式就是它自己，即 $p_n(x) \equiv p(x)$。因此，积分是精确的：
$\int_a^b p(x) \,dx = \int_a^b p_n(x) \,dx = \sum_{j=0}^n w_j p(x_j)$
这表明，一个基于 $n+1$ 个节点（对应于 $n$ 次插值）的牛顿-柯特斯公式，其代数精度至少为 $n$。[@problem_id:3401939]

#### 对称性带来的精度提升

一个有趣且重要的现象是，某些牛顿-柯特斯公式的精度会“意外地”比 $n$ 更高。这种现象源于节点和积分区间的对称性。

考虑在对称区间 $[-1, 1]$ 上的 $n+1$ 点闭式牛顿-柯特斯法则。其等距节点 $x_j = -1 + 2j/n$ 关于原点对称，即 $x_{n-j} = -x_j$。这种节点的对称性导致了权重的对称性，即 $w_{n-j} = w_j$。

为了检验精度是否能超过 $n$，我们需要测试公式对 $x^{n+1}$ 的积分误差。误差 $E[f] = \int_{-1}^1 f(x)dx - Q_n[f]$。对于 $f(x) = x^{n+1}$，误差为：
$E[x^{n+1}] = \int_{-1}^1 x^{n+1} dx - \sum_{j=0}^n w_j x_j^{n+1}$

我们分两种情况讨论 $n$ 的奇偶性：
1.  **当 $n$ 为偶数时**：此时要测试的 $x^{n+1}$ 是一个奇函数。它在对称区间 $[-1, 1]$ 上的积分为零：$\int_{-1}^1 x^{n+1} dx = 0$。同时，求积和为 $\sum_{j=0}^n w_j x_j^{n+1}$。由于节点和权重的对称性，我们可以将和式中的项配对：$w_j x_j^{n+1} + w_{n-j} x_{n-j}^{n+1} = w_j x_j^{n+1} + w_j (-x_j)^{n+1}$。因为 $n+1$ 是奇数，所以 $(-x_j)^{n+1} = -x_j^{n+1}$，配对项之和为零。此外，由于 $n$ 是偶数，$n+1$ 个节点中必有一个中心节点 $x_{n/2} = 0$，其贡献也为零。因此，整个求积和也为零。由于精确积分和求积近似值都为零，误差 $E[x^{n+1}] = 0$。这意味着当 $n$ 为偶数时，公式对 $x^{n+1}$ 也是精确的，其代数精度至少为 $n+1$。进一步的分析表明，其精度恰好是 $n+1$。

2.  **当 $n$ 为奇数时**：此时 $x^{n+1}$ 是一个偶函数，其在 $[-1, 1]$ 上的积分 $\int_{-1}^1 x^{n+1} dx = \frac{2}{n+2} > 0$。而求积和 $\sum w_j x_j^{n+1}$ 通常不等于这个值。因此，当 $n$ 为奇数时，公式的代数精度就是 $n$。

综上所述，一个具有 $n+1$ 个节点的闭式牛顿-柯特斯法则的代数精度 $m$ 为：
$m = \begin{cases} n+1  \text{若 } n \text{ 为偶数} \\ n  \text{若 } n \text{ 为奇数} \end{cases}$
这个结果可以用一个表达式概括：$m(n) = n + \frac{1+(-1)^n}{2}$。[@problem_id:3401939] [@problem_id:3401909] 开式法则也存在类似的依赖于节点数 $m$ 的奇偶性的精度表现。[@problem_id:3402003] [@problem_id:3401906]

#### 典型示例：梯形法则与辛普森法则

- **梯形法则 (Trapezoidal Rule, $n=1$)**: 使用两个节点 $x_0 = -1, x_1 = 1$。因为 $n=1$ 是奇数，代数精度为 $1$。它能精确积分所有一次及以下的多项式。
- **辛普森法则 (Simpson's Rule, $n=2$)**: 使用三个节点 $x_0 = -1, x_1 = 0, x_2 = 1$。因为 $n=2$ 是偶数，代数精度从 $n=2$ 提升到 $n+1=3$。它能精确积分所有三次及以下的多项式，尽管它只用了三个点和二次插值。[@problem_id:3401939]

### 高阶法则的局限性与不稳定性

尽管牛顿-柯特斯公式在低阶时非常有效，但随着阶数 $n$ 的增高，它们会表现出严重的不稳定性，这使其不适用于高精度计算，尤其是在谱方法等领域。这种不稳定性主要通过两个方面体现：出现负权重和权重的发散。

#### 负权重问题

一个理想的求积公式应该模仿积分算子的一个基本性质：**正定性**。即，如果一个函数 $f(x) \ge 0$，那么它的积分也应该大于等于零。如果一个求积公式的所有权重 $w_j$ 都是正的，那么这个性质自然得到保证。

然而，对于高阶闭式牛顿-柯特斯法则，情况并非如此。可以证明，当 $n=8$ 时，首次出现负权重。对于 $n=8$，$n+1=9$ 个节点，其权重序列（按比例）为 $\{989, 5888, -928, 10496, -4540, 10496, -928, 5888, 989\}$。对于 $n=9$ 和所有 $n \ge 11$ 的情况，负权重持续存在。[@problem_id:3401986]

负权重的出现是一个严重的缺陷。我们可以构造一个非负函数 $f(x) \ge 0$，它只在一个具有负权重的节点 $x_k$ 处取正值，而在其他所有节点处为零。此时，真实的积分 $\int f(x)dx > 0$，而数值求积结果 $\sum w_j f(x_j) = w_k f(x_k) < 0$。一个正函数的积分竟然得到了一个负的近似值，这在物理和工程应用中是完全不可接受的。[@problem_id:3401986] 类似地，对于开式法则，当节点数 $m \ge 3$ 时，也会出现负权重。[@problem_id:3402003]

#### 不稳定性之源：龙格现象与权重发散

牛顿-柯特斯公式的不稳定性与等距节点上的多项式插值不稳定性（即**龙格现象 (Runge's phenomenon)**）是同源的。权重 $w_i^{(n)} = \int_{-1}^1 \ell_i(x) dx$ 是拉格朗日基函数的积分。对于等距节点，当 $n$ 很大时，基函数 $\ell_i(x)$（尤其是靠近端点的）会在节点之间剧烈振荡，其振幅随 $n$ 增长而增长。

这些剧烈的振荡直接影响了权重的性质。可以证明，随着 $n \to \infty$，权重本身并不会保持有界。具体来说，一些权重的大小 $|w_i^{(n)}|$ 会无界增长，并且符号会交替出现。一个更精确的衡量标准是所有权重绝对值之和 $\sum_{i=0}^n |w_i^{(n)}|$。对于闭式牛顿-柯特斯法则，这个和会随着 $n \to \infty$ 而发散。

根据 Pólya 和 Steklov 的一个基本定理，一个内插求积序列能够对所有连续函数收敛到其真实积分的充要条件是，其权重绝对值之和 $\sum |w_i^{(n)}|$ 对所有 $n$ 是一致有界的。由于牛顿-柯特斯法则不满足此条件，因此我们不能保证其对任意连续函数的收敛性。这正是龙格现象在数值积分领域的体现，使得高阶全局牛顿-柯特斯法则变得不可靠。[@problem_id:3256279]

#### 不稳定性之量化：范德蒙矩阵的病态性

权重的计算可以被表述为一个线性代数问题。要求公式对所有次数不超过 $n$ 的单项式 $x^k$ ($k=0, \dots, n$) 精确，可以得到一个线性方程组 $V^\top w = m$，其中 $V$ 是以节点 $x_i$ 为行、幂次 $j$ 为列的**范德蒙矩阵 (Vandermonde matrix)**，即 $V_{ij} = x_i^j$，而 $m$ 是矩量向量 $m_j = \int_{-1}^1 x^j dx$。

对于等距节点，这个范德蒙矩阵是出了名的**病态 (ill-conditioned)**。矩阵的条件数 $\kappa(V)$ 度量了输入（$m$）的微小扰动对输出（$w$）的影响。对于等距节点上的范德蒙矩阵 $V$，其条件数会随着 $n$ 的增加而呈指数级增长。可以推导出一个关于 $1$-范数条件数 $\kappa_1(V)$ 的下界 $E(n)$：
$\kappa_1(V) \ge E(n) = \frac{(n+1)n^n}{2^n n!}$
利用斯特林公式 $n! \approx \sqrt{2\pi n} (n/e)^n$，可以证明 $E(n)$ 随 $n$ 指数增长，其增长基数约为 $e/2 \approx 1.36$。这种指数级的增长意味着，在有限精度计算中，当 $n$ 稍大时，求解该线性系统得到的权重将充满严重的数值误差。这为高阶牛顿-柯特斯法则的不稳定性提供了另一个定量的解释。[@problem_id:3401979]

### 在谱方法与间断伽辽金方法中的应用与启示

高阶牛顿-柯特斯公式的理论缺陷在 DG 和谱方法的实践中会转化为具体的数值问题，尤其影响到方法的稳定性。

#### 离散内积与质量矩阵

在这些方法中，我们经常需要计算形如 $(u, v) = \int_K u(x)v(x) dx$ 的 $L^2$ 内积，其中 $u, v$ 是单元 $K$ 上的多项式。这个积分通常用数值求积来近似，从而定义了一个**离散内积**：
$(u,v)_Q = \sum_{j=0}^{N} w_j u(x_j) v(x_j)$
以及一个相应的离散“范数”的平方 $\|u\|_Q^2 = (u,u)_Q$。

如果 DG 方法采用与求积节点重合的节点基（即拉格朗日基 $\ell_j(x)$），那么单元质量矩阵 $M$ 的离散计算结果 $M_{ij} = (\ell_i, \ell_j)_Q$ 会变成一个对角矩阵：
$M_{ij} = \sum_{m=0}^{N} w_m \ell_i(x_m) \ell_j(x_m) = \sum_{m=0}^{N} w_m \delta_{im} \delta_{jm} = w_i \delta_{ij}$
这种将质量矩阵对角化的技术被称为**质量集中 (mass lumping)**。此时，质量矩阵的对角元就是求积权重 $w_i$。[@problem_id:3402003] [@problem_id:3401960]

#### 能量稳定性的破坏

DG 和谱方法中许多时间演化问题的稳定性证明（**能量方法**）依赖于一个离散能量范数不随时间增长。这个离散能量通常由质量矩阵定义，例如 $E_h = \mathbf{u}^\top M \mathbf{u}$，其中 $\mathbf{u}$ 是解的系数向量。为了使 $E_h$ 成为一个合法的能量（范数的平方），质量矩阵 $M$ 必须是**对称正定的 (Symmetric Positive Definite, SPD)**。

当使用牛顿-柯特斯求积时，对角质量矩阵 $M$ 的对角元是权重 $w_j$。如果任何一个权重 $w_j$ 为负，那么 $M$ 就不再是正定的，因为我们可以选择一个系数向量 $\mathbf{u}$，它只在第 $j$ 个分量上非零，导致 $E_h = u_j^2 M_{jj} = u_j^2 w_j < 0$。一个非正定的质量矩阵意味着离散内积 $(\cdot, \cdot)_Q$ 不能定义一个真正的范数，因为它违反了正定性公理。这就从根本上破坏了标准能量稳定性证明的数学基础。[@problem_id:3401960]

#### 单元边界通量的计算

在 DG 方法中，单元间的耦合通过计算边界上的数值通量来实现。求积节点的选择会影响这一过程。如果使用**开式**牛顿-柯特斯法则，所有节点都在单元内部，因此无法直接在节点上获得解在单元边界 $a$ 和 $b$ 处的值。需要通过多项式插值从内部节点的值外插得到边界值。相反，如果使用**闭式**法则，端点 $a$ 和 $b$ 本身就是节点，这在某些情况下可以简化通量的计算。[@problem_id:3402003]

#### 结论与替代方案

由于高阶牛顿-柯特斯公式存在负权重和不稳定性问题，它们在现代高阶谱元和 DG 方法中几乎从不被用作全局求积法则。它们的主要价值在于其教学意义和作为构建更复杂法则（如复合法则）的基础。

在实践中，**高斯求积 (Gaussian quadrature)** 及其变体（如 Gauss-Legendre, Gauss-Lobatto）是首选。这些法则是基于非等距节点（多项式零点）构建的，它们具有两个关键优势：
1.  **权重始终为正**：对于任意阶数，所有权重都是正的，从而保证了离散内积的正定性。
2.  **最优代数精度**：$N+1$ 个节点的高斯求积可以达到 $2N+1$ 的代数精度，远高于牛顿-柯特斯法则。

特别是，包含端点且权重为正的 **Gauss-Lobatto** 求积，与**分部求和 (Summation-By-Parts, SBP)** 算子的要求高度兼容。SBP 算子是构建能量稳定格式的系统性工具，它要求离散内积（由一个对角范数矩阵 $H$ 定义）是正定的。高斯-洛巴托求积的权重正好可以用来构造这个正定的 $H$，从而为能量稳定的高阶 DG-SBP 格式提供了坚实的基础。[@problem_id:3401960]
